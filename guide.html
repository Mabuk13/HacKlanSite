// WHAT IS DUAL BOOTING?

Dual booting is a configuration in which a computer contains two operating systems and allows the user to select which operating system starts when the computer boots.

SYSTEM CONCEPT
OS A + OS B

A boot manager can present the available operating systems and allow the user to select one.
